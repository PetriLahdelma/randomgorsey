# Original Random Gorsey logo

Source: `so_long_spectrum.ai` in the artist archive, Adobe Illustrator25.4,16artboards,1,166,872,010bytes, dated15October2021. The original file was not saved or overwritten during recovery.

Artboard3 contains the matching two-row liquid-serif RANDOM/GORSEY mark. The PDF-compatible preview flattens its appearance, but native Illustrator2026 SVG export (artboard3, fonts Convert To Outlines, precision4) recovered twelve original glyph paths. The web assets contain those exact path data with no embedded bitmap, tracing, substituted font or external dependency.

The export included a background circle and an off-artboard raster; those were excluded from the standalone wordmark. The viewBox was cropped to the native path bounds with6units padding. Fill is adapted to studio ink/ivory for contrast; curves remain unchanged.
